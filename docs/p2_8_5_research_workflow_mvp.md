# P2.8.5 研究工作流体验 MVP

本轮已接通最短研究闭环：选择论文 → 提问 → 展开 Citation → 查看对应 PDF 页 → 保存回答为研究笔记 → 导出带引用的 Markdown 阅读记录。

实现边界：

- 上传成功后在忽略目录保存本地 PDF 副本；解析失败不会保存空索引；
- Citation 卡片可按页渲染 PDF，不修改原始论文；
- 研究笔记独立保存在 SQLite，包含问题、回答和 Citation 快照；
- 导出 Markdown 包含页码与 Chunk ID；
- 会话标题使用“论文文件名 + 首个问题类型”确定性生成，不增加 LLM 调用；
- 移除论文前展示关联笔记、批注与当前会话记忆数量并二次确认。

未进入本 MVP 的内容：跨会话论文库、多论文研究空间、PDF 逐句高亮、结构化比较工作台、React 前端、OCR 与多模态。
