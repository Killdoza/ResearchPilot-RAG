# ResearchPilot v1.1：2--3 分钟演示脚本

## 演示目标

用一个真实问题同时证明三件事：系统能定位论文证据、回答受到可信度契约约束、项目有可复现实验和工程闭环。演示不宣称生产级 SaaS、任意论文 100% 正确或成熟的跨论文 Agent。

## 演示前准备

1. 选一篇允许公开展示的文本型 AI/CS PDF；不要使用私人论文或扫描件作为成功案例；
2. 新建干净会话，预先确认 DeepSeek Key 可用且余额足够；
3. 准备两个问题：`论文报告了哪些主要实验结果？` 和 `论文是否给出了代码仓库地址？`；
4. 预先打开 Streamlit、`http://127.0.0.1:8000/docs`、README 和 E5/P2 报告；
5. 关闭含 Key、私人目录、未授权论文和历史会话的窗口。

## 逐分钟流程

### 0:00--0:25：定位与边界

口述：

> ResearchPilot 面向 AI/CS 论文精读。它不是只把 PDF 塞给大模型，而是把解析、检索、回答、引用、记忆和评测拆开，并要求事实性回答能回到论文页码。当前版本主要支持文本型 PDF；扫描件和视觉图表仍是后续工作。

快速展示 README 的架构图和真实指标表。

### 0:25--1:15：上传与可信问答

1. 上传 PDF，指出页面展示结构解析和索引状态；
2. 问：`论文报告了哪些主要实验结果？`；
3. 展示回答中的页码 Citation、Claim/数字警告和“打开 PDF 对应页”；
4. 保存一条研究笔记，展示原文证据与用户批注分离；
5. 再问完全相同的问题，若命中缓存，说明缓存保存完整 AnswerArtifact，而不只缓存纯文本。

口述重点：

> 检索采用结构感知 Parent--Child、Dense、持久化 BM25、RRF 和 CrossEncoder 重排。实验结果类问题会额外覆盖结果章节和结构化表格；缓存仍保留 Citation、Claim 与验证状态。

### 1:15--1:45：拒答和输入边界

问：`论文是否给出了代码仓库地址？`。如果全文没有 URL/DOI/代码地址，展示结构化拒答且 Citation 为 0；如果论文确有地址，则展示对应页证据。

口述：

> 这类问题会执行确定性全文字段扫描。找不到时不让模型根据常识补一个链接。跨论文严格模式同样不会在证据不足时悄悄降级为无范围比较。

### 1:45--2:25：实验事实

展示 E5 报告：只改变 Parser/Chunker 时，论文级留出 Test 的 MRR 从 0.4056 到 0.6767，Recall@5 从 0.55 到 0.80。

展示 P2 的负面结论：Scope/Gate 增强了来源边界和安全拒答，但没有自动提高总体 Citation F1，因此未设为默认产品链路。

### 2:25--2:55：工程闭环与限制

展示 Swagger 的 `/health`、`/ready`，以及 GitHub Actions 或本地门禁结果。说明 Streamlit 与 API 共用 Core；当前为 274 项自动测试、18/18 固定产品回归、36/42 预期页覆盖。

最后明确：

> 这是可评测、可追溯的本地论文研究系统，不是已经具备认证、多租户授权、任务队列和 SLA 的生产平台。

## 录屏检查表

- [ ] 只展示实测数字，明确指标口径；
- [ ] 至少展示一次 Citation PDF 页核验；
- [ ] 至少展示一次研究笔记或 Markdown 导出；
- [ ] 不把严格跨论文模式描述为已经成熟；
- [ ] 不把 `/health` 延迟描述为完整 RAG P95；

## 简历两行版

**ResearchPilot｜面向 AI/CS 论文的可评测、可追溯 RAG 系统**

实现 Docling 结构感知解析、Parent--Child 分块、Dense/BM25/RRF/CrossEncoder 混合检索、页级 Citation、论文级记忆及结构化表格/数字忠实度约束；在论文级留出 Test 上将 Recall@5 从 0.55 提升至 0.80。构建无 Oracle 泄漏的跨论文对照、失败审计、FastAPI、Streamlit、Docker、CI、脱敏 Trace 与 274 项自动测试，并将未提升 Citation F1 的严格跨论文策略保留为 Feature Flag。
